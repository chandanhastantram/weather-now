# Weather Now

A weather application with real-time weather data.

## Features

- City search
- Current weather display
- Temperature, humidity, wind speed
- Weather icons
- Min/max temperature
- Orange and white theme

## Tech Stack

- React
- Vite
- OpenWeatherMap API

## Run Locally

```bash
npm install
npm run dev
```

## API Key

The app uses OpenWeatherMap API. The demo key is included, but you can replace it with your own in `App.jsx`.

## Build

```bash
npm run build
```

## Deploy

Deploy the `dist` folder to any static hosting service.
